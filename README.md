# 🚕 CPA 커넥트 ( CPA Connect)

> **공인회계사(CPA) 1차 시험에 응시하는  학우들을 위해 개발된 [고사장별 택시 카풀 매칭 및 커뮤니티 플랫폼]입니다.**
> 매년 시험 당일 아침, 수많은 1차 수험생들이 고사장까지 개별 이동하며 겪는 교통 불편과 비용 부담을 겪습니다. 본 프로젝트는 이러한 **학내 비효율을 해소하기 위해 주도적으로 기획·개발한 IT 솔루션**입니다.

---

## ✨ 핵심 기획 및 구현 기능

### 1. 응시번호 기반 동적 고사장 자동 매칭 (Frictionless UX)
* **목적**: 사용자가 자신의 고사장 위치를 일일이 찾고 입력하는 번거로움 최소화
* **로직**: 금감원 공고 기반의 **고사장별 응시번호 매핑 테이블(20개 고사장 범위)**을 내장하여, 8자리 응시번호 입력 시 내부 데이터 정합성 검증(Regex)을 거쳐 해당 고사장 팀으로 자동 분류 및 선착순 4인 단위 호차 배정

### 2. 데이터 무결성 및 정보 보안 관리 (Security & Privacy)
* **개인정보 마스킹**: 타인에게 민감한 응시번호 및 개인 식별 정보가 노출되지 않도록 조회 섹션에서 **비밀번호 필드(`type="password"`) 처리** 및 내부 암호화 가이드 제공
* **소프트 딜리트(Soft Delete) 적용**: 매칭 취소 시 데이터를 완전 삭제(`Drop`)하지 않고, 기존 호차 배열의 순번이 뒤틀려 타 학우들에게 혼선을 주는 것을 방지하기 위해 **"❌ 취소됨(빈자리)" 상태값만 업데이트하는 로직** 구현

### 3. 실시간 트래픽 대시보드 및 멀티 탭 커뮤니티
* **실시간 현황판**: 고사장별 대기 인원 현황을 상단에 가로 스크롤 형태의 라이브 대시보드로 구현하여 매칭 수요를 한눈에 파악 가능
* **예외 케이스 대응**: 선착순 자동 호차 매칭 외에도, 출발 시간 및 장소를 커스텀하고 싶은 학우들을 위한 **[자유 모집 게시판]**과 수험생 멘탈 케어를 위한 **[합격 응원 게시판]**을 다원화하여 운영

### 4. 어드민(Admin) 통제 기능 구축
* 서비스 내 허위 정보 입력 및 악성 게시글 리스크를 통제하기 위해 **비밀번호 기반의 시스템 관리자 전용 익스팬더**를 구축. 실시간 데이터 백업(CSV 다운로드) 및 특정 유저/게시글 직권 제외 기능을 구현하여 백엔드 관리 역량 증명

## 📈 데이터 아웃풋 구조 (Data Architecture)

프로그램 실행 시 발생할 수 있는 데이터 유실을 방지하기 위해 파일 시스템 기반의 가벼운 데이터베이스(CSV) 3원화 구조를 채택했습니다.
* `cpa_db.csv`: 신청자 정보, 매칭 상태, 매너 스타일, 오픈채팅 링크 관리
* `cpa_board.csv`: 자유 모집 게시판 데이터 축적
* `cpa_cheer.csv`: 익명 응원 메시지 및 타임스탬프 기록
